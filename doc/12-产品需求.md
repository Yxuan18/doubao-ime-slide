# PRD — 豆包下滑快捷键

> 只写"做什么、不做什么"。实现见 [`13-架构.md`](13-架构.md)，
> 实测记录见 [`../ACCEPTANCE.md`](../ACCEPTANCE.md)，扩展取舍见 [`06-逆向-总览与可扩展点.md`](06-逆向-总览与可扩展点.md)。

## 1. 要解决的问题

豆包输入法的 26 键键盘没有自定义手势。复制、粘贴、剪切、全选、撤销都要离开字母区，
经选中 / 长按 / 工具栏完成（具体步数与耗时未计时，**待确认**）。

目标：在不改变任何原生行为的前提下，让这五个动作在字母区一步完成。

## 2. 目标用户

- 主要用户是作者本人——`app/build.gradle.kts` 注明"自用模块：复用 debug 签名"。
- 使用场景：中文拼音 26 键与英文 26 键字母面。
- 是否有作者以外的使用者：**待确认**（仓库公开，但没有使用数据）。

## 4. 功能边界（明确不做）

来自 `doc/06` §2.4，逐条都有当时的技术理由：

| 不做 | 理由 |
|---|---|
| 重造光标滑动 | 豆包 native 已有 `ui::Slider` / `cursor_slide`，再造会抢事件 |
| 往键盘上叠自绘提示 | 键盘是 native 自绘位图，叠 View 会与候选栏、浮层抢层级 |
| 主动 `switchKeyboard` 自检 | 会打断用户输入，只能用在测试构建 |
| 用 `SettingsContentProvider` | 受 `signatureOrSystem` 保护，进程内读 `SettingsConfigNext` 即可 |
| 把死区改成补发轻点 | 等于用误输入换反馈，与死区存在的理由冲突 |
| 支持非 26 键棋盘 | 几何与判定都按字母面标定 |
| 免 root / LSPatch 使用 | 未验证；容器方案对输入法不可行（系统只认已安装包名的 IME 服务） |

## 5. 约束

- 豆包输入法 **1.5.3** 验收；其他版本未验证（钩的是 `nativeTouch` 具体签名）。
- 键盘视图 **1080×909**、顶边在屏幕 y=1401 上逐像素标定；其他分辨率、横屏、悬浮未实测。
- 运行环境：Android 16 / API 36，LSPosed 2.2.0-it，Xposed API 82（legacy）。
- 模块只做手势与设置页；不改豆包的布局、皮肤、词典。
