# 设计规范（设置页与图标）

> 范围只有**模块自己的界面**：设置页与启动图标。键盘本体是豆包 native 绘制的位图，
> 模块不参与渲染（`doc/08` §5）。
> 规范全部来自现有代码与资源，不是新设计；改动前先对照出处。

## 1. 基本原则

取自 `SettingsActivity` 类注释（`app/src/main/java/app/xuan/doubaoslide/SettingsActivity.java`）：

1. 整页只回答两件事：**怎么设**、**现在成不成**。
2. 只有一个彩色元素（开关轨道），其余用系统主/次文本色。
3. 规则线只画在"换了一件事说"的地方，不逐行画。
4. 等宽字体只给需要字符对齐的数据（路径、pid、时间）；版本号与白话用系统字族。
5. 颜色跟系统深浅色走，不自己发明配色。

## 2. 色板

| 名称 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `accent` | `#A9691F` | `#C8873C` | 唯一强调色，只用于开关轨道 |
| 图标底 | `#14181F` | 同 | 自适应图标背景层 |
| 正文 | `?android:attr/textColorPrimary` | 同（系统） | 标题、状态句、行值 |
| 次文 | `?android:attr/textColorSecondary` | 同（系统） | 行标签、说明 |
| 分割线 | 正文色 10% alpha | 同 | `hairline()` |

出处：`app/src/main/res/values/colors.xml`、`values-night/colors.xml`。
**不要用** `?android:attr/colorAccent`：本机 MIUI 把 DeviceDefault 的强调色改成了灰，
开关"开/关"就只差拨杆位置。亮色下取深一档是因为白拨杆对轨道的对比度 3.0:1 卡在及格线。

## 3. 字体与字号

| 元素 | 字号 | 字族 |
|---|---|---|
| 页面标题 | 24sp | `sans-serif-medium` |
| 状态句（页面顶部的结论） | 15sp | 系统，行距 5dp |
| 开关主文案 / 行标签 | 15sp / 13sp | 系统 |
| 副标题、说明 | 14sp / 13sp | 系统 |
| 等宽数据（路径、pid、时间） | 12sp | `MONOSPACE` |

主题继承 `Theme.DeviceDefault.Light.NoActionBar`，`windowBackground` 用
`?android:attr/colorBackground`——与内容区同色，否则状态栏下会多出一条更深的带。

## 4. 间距

| 位置 | 值 |
|---|---|
| 页面左右内边距 | 24dp |
| 顶部 / 底部 | 28dp / 36dp |
| 标题 → 副标题 | 8dp |
| 副标题 → 开关行 | 22dp |
| 开关行 → 分割线 | 18dp（线后接状态句，再 18dp） |
| 详情行 | 上下 7dp，标签列宽 88dp |
| 开关行最小高度 | 52dp |

## 5. 文案规则

状态句是全页唯一的"结论"，按失败类型分别说话（`SettingsActivity.statusSentence`）：

| 情况 | 说法 |
|---|---|
| 没注入 | 去 LSPosed 启用本模块、作用域勾豆包、重启输入法 |
| 钩子没挂上 | 豆包的触摸接口变了，手势不会触发 |
| 动作通道没接上 | 手势能判出来，快捷键不会执行 |
| 上次快捷键在模块侧失败 | 动作通道可能已经不通了 |

**不报警**的情况：`editor`（编辑器自己拒绝，例如没选区时复制）——日常就会发生，
报了就是天天误报。判据见 `Actions.LAST_RESULT`。

## 6. 图标

自适应图标三层（`mipmap-anydpi-v26/ic_launcher.xml` + `drawable/ic_launcher_foreground.xml`），
背景色 `#14181F`。桌面显示名用 `app_name_short`（"下滑快捷键"）：
完整名"豆包下滑快捷键"在 5 个汉字处会被 MIUI 截断（`values/arrays.xml` 注释）。
