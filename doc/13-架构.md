## 3. 分层

| 层 | 类 | 能否单元测试 |
|---|---|---|
| 注入装配 | `XposedEntry`、`BoardGuard`、`SlideHook` | 否：依赖反射与 Xposed |
| 纯判定 | `GestureGate`、`Geometry` | **是**（43 项单测锁在这里） |
| 执行 | `Actions` | 否：依赖 `InputConnection` |
| 诊断 | `Log`（写）、`Diagnostics`（读）、`SettingsActivity`（展示） | 否：依赖文件与 Activity |

边界规则：判定层不碰反射、不碰 `View`；执行层不做判断；诊断层不改行为。

## 4. 触摸调用链

```
View.onTouchEvent
  └─ KeyboardView.nativeTouch(handle,x,y,action,time)   ← 钩子挂在这里
       └─ SlideHook.dispatch
            ├─ BoardGuard.kbdType()        读引擎当前棋盘（每次按下重读，不缓存）
            ├─ Geometry.letterAt(x,y,w,h)  坐标 → 字母（越界返回 0）
            ├─ GestureGate.onDown/onEvent/onUp
            │     ├─ FIRE    → Actions.perform(action) → Log.fire(仅诊断)
            │     ├─ DEAD    → 什么都不做
            │     ├─ REPLAY  → 按原坐标/时间戳整段补发
            │     └─ HANDBACK→ 把 DOWN 归还引擎，让长按浮层能画
            └─ 补发：反射调 nativeTouch，用 ThreadLocal REPLAYING 放行自己
```

### 判定表（视图高 909 时 `FIRE`=60px、`GATE`=12px；比例见 `Geometry`）

| 条件 | 结论 |
|---|---|
| `maxDy > FIRE` | FIRE：触发快捷键（带触感） |
| 向下 `maxDy > GATE` 且终点没回到起点上方 | DEAD：作废，不打字也不触发 |
| 其余（轻点 / 上滑 / 横滑） | REPLAY：按原坐标、原时间戳、原顺序整段补发 |
| 见过第二根手指（`action=5`） | REPLAY：跳过快捷键判定，整段补发 |
| 按住 `HAND_BACK_MS`（300ms）没滑过 FIRE | HANDBACK：把这次按下归还引擎，让长按浮层能画出来 |
| 归还后横移 > 24px 且大于纵移 | 整段交给引擎（长按浮层里选字），不触发快捷键 |
| 引擎发来 `LEAVE(-1)` | 已归还时放行（引擎要靠它画浮层第二格）；未归还时吞掉，且不清判定状态 |

三条不变量（详见 `CLAUDE.md`）：引擎在归还前看不到被映射键的 DOWN；补发必须整段，
不能压平成 DOWN+UP；反射调用会再次进钩子，必须用 `REPLAYING` 放行。

## 5. 配置与诊断数据流

```
【配置】
SettingsActivity ─写─> SharedPreferences("settings")
      │                   └─ LSPosed 重定向到共享目录；prefs 文件置 0644
      └─ 每次 commit 后 setReadable(true,false)：LSPosed 不改权限
                                  │
                     豆包进程 Log.refresh()（每根手指按下一次）
                        读不到 → 回落 Config.DEFAULT_DEBUG，键盘不会哑

【诊断（反向）】
XposedEntry 装配完 ──> Log.heartbeat(proc, hooked, svc) ──┐
                                                        ├─> 共享目录下两个文件（均预建 0666）
SlideHook 触发快捷键 ─> Log.fire(action, result) ─────────┘   （均有 4096 字节滚动窗口）
      （异步：单线程守护 executor，积压 8 条即丢，不挡 UI 线程）

SettingsActivity ──> Diagnostics.read() 只读文件末尾窗口
```

## 6. 数据契约

| 名称 | 值 | 说明 |
|---|---|---|
| prefs 文件 | `settings` | `Config.PREFS` |
| prefs 键 | `debug` | 布尔，运行时日志开关 |
| 默认值 | `Config.DEFAULT_DEBUG` | `true`；发布清单要求保持 `true`（2026-10-28 决定） |
| 心跳行 | `<epochMillis> <进程名> pid=<pid> hooked=<bool> svc=<bool>` | 装配**之后**写，否则钩子失败也会显示"已注入" |
| 执行行 | `<epochMillis> <动作> result=<ok\|nochannel\|noresid\|exception\|editor>` | 只有前四种模块侧失败会报警 |
| 滚动窗口 | `Config.LOG_WINDOW = 4096` | 写侧截断与读侧窗口必须一致 |
